# Ammar Fakhri e-Portfolio

This is the personal e-portfolio of Muhammad Ammar Fakhri bin Taib, an IT Diploma student at UTHM. It is made with plain HTML, CSS and JavaScript. It works on phone, tablet and computer.

## Pages

1. index.html is the Home page. It has my photo, About me, Skills and Projects.
2. cover.html is the Cover Letter page. You can read the PDF or download it.
3. resume.html is the Resume page. You can read the PDF or download it.
4. jobsites.html has my LinkedIn and JobStreet profile links.
5. gallery.html has my photos. Tap a photo to see it bigger.

## Files and folders

Keep everything in one folder like this:

- index.html, cover.html, resume.html, jobsites.html, gallery.html
- style.css (the design)
- script.js (the phone menu and the photo viewer)
- pdf folder (put the cover letter and resume PDF files here)
- picONLY folder (put all the photos here)

The folder names pdf and picONLY must be exactly like this. If the names are different, the photos and PDF files will not show.

## How to open the website on your computer

1. Put all the files and folders together in one folder.
2. Double-click index.html.
3. The website opens in your browser.

## How to put the website online (GitHub Pages)

1. Create a new repository on GitHub.
2. Upload all the files and folders to the repository.
3. Click Settings, then click Pages.
4. Under Branch, choose main and click Save.
5. Wait one or two minutes. GitHub will show your website link.

## How to change things

- To change the About text, skills or projects: open index.html and edit the words.
- To change the resume or cover letter: put the new PDF in the pdf folder with the same file name.
- To change the colours: open style.css and edit the colour values at the top of the file.
- To add a photo to the gallery: put the photo in the picONLY folder. In gallery.html, copy one photo block, then change the photo name and the words.

## Important before sharing

The Resume page shows a phone number and home address. The Job Sites page shows an email address. If you do not want everyone to see these, delete them before putting the website online.
